# Tool thêm tên hàng loạt

Mở `index.html` bằng Chrome hoặc Edge, sau đó:

1. Kéo một file HTML (hoặc file bất kỳ) vào vùng chọn file.
2. Nhập các tên muốn thêm, mỗi tên trên một dòng hoặc phân cách bằng dấu phẩy.
3. Kiểm tra danh sách tên file ở phần xem trước.
4. Chọn **Lưu tất cả vào thư mục** hoặc **Tải một file ZIP**.

Ví dụ file nguồn `game.html`, dấu ngăn cách `_`, danh sách `facebook`, `tiktok` sẽ tạo `game_facebook.html` và `game_tiktok.html`. Nội dung file không bị thay đổi.
